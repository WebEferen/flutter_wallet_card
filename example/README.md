# flutter_wallet_card_example

Demonstrates how to use the flutter_wallet_card plugin.

## iOS: Swift Package Manager and CocoaPods

The plugin supports both Swift Package Manager (SPM) and CocoaPods.

This example app is migrated to SPM, like the example generated by
`flutter create -t plugin`. Once Flutter adds the local SPM overrides for the
plugin to the example Xcode project, the example can no longer be built with
SPM disabled, so it has no `Podfile`:

```bash
flutter config --enable-swift-package-manager
flutter build ios --simulator
```

To check the CocoaPods integration, build a new app that depends on the plugin
with SPM disabled:

```bash
flutter config --no-enable-swift-package-manager
flutter create --platforms ios pods_check && cd pods_check
flutter pub add flutter_wallet_card --path ..
flutter build ios --simulator
```
